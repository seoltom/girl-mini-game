# 「그 여름의 기록」 — 작품 컨셉

> 일본 미연시 스타일의 청춘 일상 미니 데모.  
> 엔딩 2개, 총 5~7분 분량의 프로토타입.

---

## 1. 한 줄 컨셉

> _"그 해 여름, 도서부에서 처음 마주친 그녀 — 그 만남이 그 이후의 모든 계절을 바꾸었다."_

---

## 2. 톤 & 무드

| 항목 | 방향 |
|---|---|
| 장르 | 청춘 일상 / 순정 / 슬라이스 오브 라이프 |
| 시대 | 현대 한국, 2020년대 여름 |
| 무드 키워드 | 햇살 · 종이 냄새 · 오후 · 조용한 도서부 · 옥상 석양 |
| 일본 미연시 표준 | 타이틀 일러스트 + 반투명 텍스트박스 + 캐릭터 좌/우 + 세이브/로드/스킵/백로그 |
| **분위기 톤 (필수)** | _잔잔함, 정적, 한 끗의 따뜻함_. 드라마틱한 갈등·반전 없이 "함께한 시간" 자체를 미화하는 톤. |

## 3. 등장인물

### 성빈 (성빈 / Sungbin) — 주인공 (1인칭 시점, 얼굴 비공개)
- **학년**: 고2. 도서부원.
- **성격**: 조용하고 내성적. 말수가 적지만 상황 파악이 빠름.
- **미연시 관습**: 주인공 얼굴은 보여주지 않거나 실루엣 처리. (`mc_silhouette.png`)
- **첫 대사 톤 가이드**: 한 문장, 짧게 끊기. 일본 미연시 주인공 특유의 "심정 묘사보다 행동 묘사".

### 柚奈 (유나 / Yuna) — 히로인
- **학년**: 고1. 요리부 신입, 도서부 겸부.
- **외모 시안**: 중간 키, 갈색 단발(어깨 아래 약간), 부드러운 갈색 눈, 왼쪽에 작은 보조개.
- **성격**: 밝고 사교적. 감정 표현이 솔직한 편. 가끔은 부끄러워함.
- **복장**: 교복 (블레이저 + 체크 스커트 + 리본 타이). 도서부에서는 가끔 소매 풀어 입음.
- **스탠딩 표정 변주 4종**:
  - `yuna_default` — 기본 미소 (가장 자주 등장)
  - `yuna_smile` — 환하게 웃는 얼굴 (친밀도 +)
  - `yuna_shy` — 부끄러운 표정 (감정선 변곡점)
  - `yuna_surprise` — 놀란 표정 (첫 만남, 깜짝 등장)

## 4. 시놉시스 (미니 데모 5~7분)

### Act 1 — 오프닝
- 교정 (오후 햇살) → 성빈 독백 → 도서부 향하는 길
- BGM: 잔잔한 피아노 (`theme_opening`)

### Act 2 — 첫 만남
- 도서부 앞 복도에서 유나(후배)와 우연히 마주침
- 선택지 1: 친절하게 / 경계하기 → 2가지 루트로 분기
- BGM: 일상 어쿠스틱 (`theme_daily`)

### Act 3 — 도서부 진입
- 유나와 함께 도서부 안으로
- 선택지 2: 책 추천 / 편하게 읽기 → 2가지 결말 변주
- BGM: 잔잔한 어쿠스틱 (`theme_tender`)

### Act 4 — 엔딩 (2종)
- **End_Together** (함께): 옥상 석양, 유나가 책 다 읽었다고 함 → 엔딩 CG
- **End_Alone** (혼자): "다른 결말이 기록되었습니다" → 엔딩 CG
- BGM: 엔딩곡 (`theme_ending`)

## 5. 비주얼 규약 (일본 미연시 표준)

| 요소 | 규칙 |
|---|---|
| 화면 비율 | 16:9 (1280×720) |
| 텍스트박스 | 하단 검정 반투명 박스 + 흰 글씨 + 좌측 상단 이름 박스 |
| 캐릭터 배치 | `left` / `center` / `right` 3포지션 |
| 페이드 | 배경/캐릭터/CG 교체 시 `fadeIn 1~2s` / `fadeOut 0.5~1s` |
| 이름 박스 | 흰 박스 + 검정 글씨, 라운드 2px |
| 컨트롤 버튼 | 우측 상단 동그라미 (세이브/로드/히스토리/스킵/오토/설정) |
| CG 표시 | 풀스크린 + 페이드인 2s + 잠시 정적 후 다음 진행 |

## 6. 다음 단계 (확장)

이 미니 데모가 마음에 들면, 다음과 같이 확장 가능:

1. **히로인 추가**: 히로인 1 → 2 → 3 (각자 루트·엔딩 1개씩)
2. **분기 깊이**: 선택지를 2개에서 4~6개로 확장
3. **CG 갤러리**: 본편 클리어 후 CG 감상 모드 (`/gallery.html` 별도)
4. **보컬 BGM**: 오프닝곡 / 엔딩곡을 가사 있는 보컬곡으로 (DOVA·니코동 무료 가라오케 활용)
5. **배포**: Steam 등록 / BOOTH 판매 / 자체 플랫폼 (예: 소설 플랫폼 운영자라면 본인 사이트 내장)
