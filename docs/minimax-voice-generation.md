# MiniMax 작업 지시서: 일본어 음성 및 한·일 자막 적용

아래 내용을 MiniMax 코딩 에이전트에 전달하고, 작업 디렉터리를 이 프로젝트 루트(`/Users/seoltom/Work/girl-game`)로 지정해 주세요.

---

## 요청

이 저장소는 Monogatari 기반 비주얼 노벨 **「그 여름의 기록」**입니다. 시나리오의 대사와 내레이션에 일본어 음성을 추가하고, 대화창에는 **일본어를 위에, 한국어 번역을 아래에** 동시에 표시해 주세요.

한국어 음성은 만들지 않습니다. 음성 파일은 일본어만 생성합니다.

## 기존 음성 설정

- 유나: `Japanese_GracefulMaiden`
- 주인공 성빈의 독백·내레이션: `Japanese_OptimisticYouth`
- 출력 형식: MP3, 32,000 Hz, mono, 기본 속도 0.95
- 기존에 있는 음성 파일은 재사용하고, 빠진 대사만 추가합니다. 기존 파일을 임의로 덮어쓰지 마세요.

## 작업 순서

1. `js/script.js`를 읽고 모든 한국어 발화와 내레이션을 빠짐없이 목록화합니다. 선택지의 발화도 포함합니다. 시스템 명령, 효과음 지시, 장면 설명은 음성 대상에서 제외합니다.
2. 각 한국어 문장을 자연스러운 일본어 회화 또는 독백으로 번역합니다. 유나의 말투는 부드럽고 자연스러운 여고생 말투로, 성빈의 독백은 차분한 남성 독백으로 맞춥니다. 고유명사 `유나`는 `ユナ`, `성빈`은 `ソンビン`으로 표기합니다.
3. 게임의 한 문장당 하나의 MP3 파일을 `assets/voices/` 아래에 생성합니다. 기존 파일명은 유지하고, 새 파일은 충돌하지 않는 규칙적인 이름을 사용합니다. 예: `yuna_friendly_01.mp3`, `mc_start_01.mp3`.
4. 제공된 `batch_text_to_audio` 기능을 사용합니다. 각 요청에 일본어 텍스트, 위에서 지정한 `voice_id`, `output_file_path`, `format: "mp3"`, `sample_rate: 32000`, `speed: 0.95`를 지정합니다. API 키나 인증 정보는 저장소 파일에 쓰지 않습니다.
5. `js/assets.js`에 생성한 음성 파일을 등록하고, `js/script.js`에서 해당 발화 직전에 알맞은 `play voice <asset-key>`를 실행하도록 연결합니다. 한 대사의 음성이 끝나기 전에 다음 음성이 시작되지 않게 합니다.
6. 같은 대사의 기존 일본어 별도 내레이션/번역 줄이 있다면 중복 재생 또는 중복 표시가 되지 않도록 정리합니다.
7. 대화 UI를 수정하여 일본어 음성의 원문을 윗줄, 기존 한국어 문장을 아랫줄에 표시합니다. 기존 화자 이름, 선택지, 넘기기·자동 재생 기능은 유지합니다. 내레이션에도 같은 2줄 형식을 적용합니다.
8. `index.html`의 캐시 버전을 갱신하고, 시작부터 두 선택지 분기 및 엔딩까지 음성·자막·넘기기 동작을 확인합니다.

## 구현 기준

- 시나리오 문장을 일괄 정규식으로 파싱해 화자나 문장 내용을 망가뜨리지 마세요. Monogatari의 기존 명령 문자열과 선택지 구조를 유지하세요.
- 자막은 실제 일본어 번역 + 원래 한국어 문장을 각각 별도 줄로 보여 주세요. 일본어를 괄호로 감싸거나, 일본어와 한국어를 한 줄에 이어 쓰지 마세요.
- 기존의 한국어 음성 파일이 있더라도 재생하지 않습니다. 일본어 음성만 사용합니다.
- 모든 오디오 경로가 실제 파일과 일치하는지 확인합니다. 생성하지 못한 파일을 등록하거나 빈 음성 파일을 만들지 마세요.
- 완료 후 새로 생성한 음성 파일 목록, 처리한 발화 수, 테스트 결과를 보고합니다.

## 기존 주요 파일

- 시나리오: `js/script.js`
- 오디오 에셋 등록: `js/assets.js`
- 대화 UI 스타일: `style.css`
- 앱 진입점·캐시 버전: `index.html`
- 현재 음성 파일: `assets/voices/`
